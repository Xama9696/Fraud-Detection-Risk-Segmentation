# 💳 Fraud Detection & Risk Segmentation

This project focuses on detecting fraudulent credit card transactions using machine learning and introducing a basic risk segmentation approach.

A classification model is trained on transaction data to identify whether a transaction is fraudulent or not. The dataset consists of anonymized features (V1–V28), along with transaction time and amount.

To enhance interpretability, a fraud probability score is generated for each transaction and used to categorize transactions into different risk levels such as Low, Medium, and High risk.

A Tableau visualization is created to analyze the distribution of fraudulent and non-fraudulent transactions. The chart highlights the strong class imbalance typically observed in real-world fraud detection problems.

---

## 🛠️ Technologies Used

Python, Pandas, NumPy, Scikit-learn, Tableau

---

## ⚙️ Workflow

- Data preprocessing and feature handling  
- Training a classification model for fraud detection  
- Generating fraud probability scores  
- Creating risk-based segmentation  
- Visualizing fraud distribution using Tableau  

---

## 📊 Output

- Fraud vs Non-Fraud classification  
- Risk segmentation of transactions  
- Tableau chart showing fraud distribution  

---

## 🧠 Key Insights

- Fraud transactions are significantly lower compared to normal transactions  
- Class imbalance is a key challenge in fraud detection  
- Risk-based segmentation helps prioritize suspicious transactions
